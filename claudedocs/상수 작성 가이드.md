# Constants (상수) 관리 가이드

**버전:** 1.0.0
**작성일:** 2026-01-15
**목적:** 프로젝트 전반의 상수 관리 방법론

---

## 개요

이 프로젝트는 **계층적 상수 구조**를 따릅니다:
- **Shared Constants:** 모든 Feature에서 공통으로 사용하는 상수
- **Feature Constants:** 각 Feature 전용 상수

---

## Shared Constants

### 구조

```
src/shared/constants/
├── app.ts              # 애플리케이션 상수
├── ui.ts               # UI/UX 상수
├── validation.ts       # 검증 상수
└── index.ts            # 진입점
```

### 사용 예시

```typescript
// ✅ 어디서든 import 가능
import { API, ROUTES, PAGINATION } from '@/shared/constants';
import { COLORS, BREAKPOINTS, Z_INDEX } from '@/shared/constants';
import { REGEX, LENGTH, FILE } from '@/shared/constants';

// 사용
const apiUrl = API.BASE_URL;
const loginUrl = ROUTES.PUBLIC.LOGIN;
const primaryColor = COLORS.primary[500];
const emailRegex = REGEX.EMAIL;
```

### 주요 상수 카테고리

#### 1. app.ts - 애플리케이션 상수

| 카테고리 | 내용 | 예시 |
|---------|------|------|
| **API** | API 관련 | BASE_URL, TIMEOUT, STATUS |
| **ROUTES** | 라우팅 경로 | PUBLIC.HOME, PROTECTED.DASHBOARD |
| **STORAGE_KEYS** | 스토리지 키 | AUTH_TOKEN, USER_PREFERENCES |
| **TIME** | 시간 상수 | SECOND, MINUTE, HOUR |
| **DELAY** | 디바운스 시간 | INPUT, SEARCH, SCROLL |
| **PAGINATION** | 페이지네이션 | DEFAULT_PAGE_SIZE, PAGE_SIZE_OPTIONS |
| **APP** | 앱 메타데이터 | NAME, VERSION, ENV |

#### 2. ui.ts - UI/UX 상수

| 카테고리 | 내용 | 예시 |
|---------|------|------|
| **BREAKPOINTS** | 화면 크기 | SM: 640, MD: 768, LG: 1024 |
| **Z_INDEX** | 쌓임 순서 | MODAL: 1050, TOOLTIP: 1070 |
| **DURATION** | 애니메이션 시간 | FAST: 150, NORMAL: 300 |
| **COLORS** | 색상 팔레트 | primary, success, error |
| **GRID** | 그리드 시스템 | COLUMNS: 12, GAPS |
| **SPACING** | 간격 | 1: 4px, 4: 16px, 8: 32px |
| **FONT_SIZES** | 폰트 크기 | SM: 14px, BASE: 16px |
| **SHADOWS** | 그림자 | SM, MD, LG |

#### 3. validation.ts - 검증 상수

| 카테고리 | 내용 | 예시 |
|---------|------|------|
| **REGEX** | 정규식 패턴 | EMAIL, PHONE, PASSWORD |
| **LENGTH** | 길이 제한 | USERNAME.MIN/MAX |
| **FILE** | 파일 제한 | MAX_SIZE, IMAGE_TYPES |
| **PASSWORD_POLICY** | 비밀번호 정책 | MIN_LENGTH, REQUIREMENTS |

## Feature Constants

### 구조

각 Feature는 독립적인 constants 파일을 가집니다:

```
features/
├── auth/
│   └── constants/
│       └── index.ts        # 인증 관련 상수
├── dashboard/
│   └── constants/
│       └── index.ts        # 대시보드 관련 상수
└── products/
    └── constants/
        └── index.ts        # 제품 관련 상수
```

### 사용 예시

```typescript
// ✅ Feature 내부에서 import
import { PRODUCT_STATUS, PRODUCT_CATEGORY } from '../constants';

// ✅ 다른 Feature에서도 import 가능 (권장하지 않음)
import { PRODUCT_STATUS } from '@/features/products/constants';

// 사용
const status = PRODUCT_STATUS.ACTIVE;
const category = PRODUCT_CATEGORY.SUBSCRIPTION;
```

### Feature Constants 예시

#### auth/constants/index.ts

- **AUTH_STATUS:** 인증 상태 (UNAUTHENTICATED, AUTHENTICATED)
- **USER_ROLE:** 사용자 역할 (ADMIN, USER, GUEST)
- **OAUTH_PROVIDER:** OAuth 프로바이더 (GOOGLE, GITHUB)
- **AUTH_LIMITS:** 인증 제한 (MAX_LOGIN_ATTEMPTS, LOCKOUT_DURATION)
- **TOKEN:** 토큰 관련 (ACCESS_EXPIRY, REFRESH_EXPIRY)
- **AUTH_FORM_MESSAGES:** 폼 검증 메시지
- **AUTH_ERROR_MESSAGES:** 에러 메시지
- **AUTH_SUCCESS_MESSAGES:** 성공 메시지

#### products/constants/index.ts

- **PRODUCT_STATUS:** 제품 상태 (ACTIVE, INACTIVE, ARCHIVED)
- **PRODUCT_CATEGORY:** 제품 카테고리 (SUBSCRIPTION, ONE_TIME)
- **PRODUCT_SORT_OPTIONS:** 정렬 옵션
- **DEFAULT_PRODUCT_FILTERS:** 기본 필터
- **PRODUCT_PAGINATION:** 페이지네이션 설정
- **PRODUCT_LIMITS:** 제품 관련 제한
- **PRODUCT_IMAGE:** 이미지 관련 상수
- **PRODUCT_FORM_MESSAGES:** 폼 메시지

#### dashboard/constants/index.ts

- **WIDGET_TYPE:** 위젯 타입 (STATS, CHART, LIST)
- **CHART_TYPE:** 차트 타입 (LINE, BAR, PIE)
- **DASHBOARD_PERIOD:** 대시보드 기간 (TODAY, WEEK, MONTH)
- **WIDGET_SIZE:** 위젯 크기 (SMALL, MEDIUM, LARGE)
- **ACTIVITY_TYPE:** 액티비티 타입 (CREATE, UPDATE, DELETE)
- **CHART_COLORS:** 차트 색상

## 상수 정의 가이드라인

### ✅ 좋은 예시

```typescript
// ✅ 의미 있는 이름과 구조화
export const PRODUCT_STATUS = {
  ACTIVE: 'active',
  INACTIVE: 'inactive',
  ARCHIVED: 'archived',
} as const;

// ✅ 타입 추론 지원
export type ProductStatus = (typeof PRODUCT_STATUS)[keyof typeof PRODUCT_STATUS];

// ✅ 라벨 별도 정의
export const PRODUCT_STATUS_LABELS: Record<ProductStatus, string> = {
  active: '활성',
  inactive: '비활성',
  archived: '보관',
} as const;
```

### ❌ 나쁜 예시

```typescript
// ❌ 매직 넘버 사용
const isActive = status === 1;

// ❌ 흩어진 정의
export const ACTIVE = 'active';
export const INACTIVE = 'inactive';
export const ARCHIVED = 'archived';

// ❌ 타입 안전성 부족
export const STATUS = ['active', 'inactive', 'archived'];
```

## 상수 위치 가이드

### Shared vs Feature Constants

| 조건 | 위치 | 예시 |
|------|------|------|
| **여러 Feature에서 사용** | shared/constants | API.BASE_URL, COLORS.primary |
| **Feature 전용** | features/*/constants | PRODUCT_STATUS, AUTH_STATUS |
| **범용 UI 설정** | shared/constants/ui.ts | BREAKPOINTS, FONT_SIZES |
| **Feature UI 설정** | features/*/constants | CHART_COLORS, WIDGET_SIZE |

## 상수 추가 절차

### 1. Shared Constants 추가

1. **적절한 파일 선택:**
   - 애플리케이션 전반 → `app.ts`
   - UI/UX 관련 → `ui.ts`
   - 검증 관련 → `validation.ts`

2. **상수 정의:**
   ```typescript
   export const MY_CONSTANT = {
     KEY: 'value',
   } as const;
   ```

3. **index.ts에 export:**
   ```typescript
   export * from './my-new-file';
   ```

### 2. Feature Constants 추가

1. **Feature constants 파일 생성 (없는 경우):**
   ```bash
   mkdir -p src/features/my-feature/constants
   touch src/features/my-feature/constants/index.ts
   ```

2. **상수 정의:**
   ```typescript
   export const MY_FEATURE_CONSTANT = {
     // ...
   } as const;
   ```

## TypeScript 활용

### as const 활용

```typescript
// ✅ 불변성 보장
export const STATUS = {
  ACTIVE: 'active',
  INACTIVE: 'inactive',
} as const;

// ✅ 타입 추론
type Status = (typeof STATUS)[keyof typeof STATUS];
// type Status = 'active' | 'inactive'
```

### Record 타입 활용

```typescript
// ✅ 라벨 매핑
export const LABELS: Record<Status, string> = {
  active: '활성',
  inactive: '비활성',
};
```

## 모범 사례

### 1. 상수로 매직 넘버 제거

```typescript
// ❌ Before
if (price > 1000000) {
  // ...
}

// ✅ After
import { NUMBER_RANGE } from '@/shared/constants';

if (price > NUMBER_RANGE.PRICE.MAX) {
  // ...
}
```

### 2. 상수로 문자열 리터럴 통합

```typescript
// ❌ Before
if (status === 'active') { /* ... */ }
if (status === 'inactive') { /* ... */ }

// ✅ After
import { PRODUCT_STATUS } from '@/features/products/constants';

if (status === PRODUCT_STATUS.ACTIVE) { /* ... */ }
if (status === PRODUCT_STATUS.INACTIVE) { /* ... */ }
```

### 3. 관련 상수 그룹화

```typescript
// ✅ 관련 상수를 객체로 묶기
export const API = {
  BASE_URL: '/api',
  TIMEOUT: 10000,
  RETRY_COUNT: 3,
  STATUS: {
    OK: 200,
    NOT_FOUND: 404,
  },
} as const;
```
